# pos-releases

Builds de **piloto** do POS Yummy (app do garçom na maquininha), para o terminal de desenvolvimento em teste com o cliente.

O app do build `piloto` lê `releases/latest/download/piloto.properties` e se atualiza sozinho. Publicação por `scripts/publica-piloto.sh` no repo `yummyfoodtech/pos`.

Não é o canal de produção: terminal de produção é atualizado pelo TMS da Stone.
